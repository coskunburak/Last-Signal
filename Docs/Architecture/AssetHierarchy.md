# Asset hierarchy

`Assets/LastSignal` contains content authored for Last Signal. `Assets/ThirdParty` contains imported packages and their original internal structures. Keep new project assets in the studio tree; do not add them to a vendor package. Preserve the asset and its `.meta` file together when moving it so Unity's GUID-based Inspector references remain intact.

| Directory | Content |
| --- | --- |
| `Art` | Studio-owned textures and other source art |
| `Animations` | Animation clips and controllers |
| `Data` | ScriptableObject definitions and gameplay profiles |
| `Materials` | Studio-owned materials |
| `Models` | Studio-owned meshes and model source files |
| `Prefabs` | All studio-owned prefabs, grouped by gameplay area |
| `Scenes/Production` | Shipping game scenes |
| `Scenes/Validation` | Test and acceptance scenes |
| `Scenes/Recovery` | Preserved recovery scenes; not part of the build |
| `Scripts/Runtime`, `Scripts/Editor`, `Scripts/Tests` | Runtime code, authoring tools and tests |
| `Settings` | Input and rendering settings |
| `Shaders` | Studio-owned shaders |

The runtime zombie prefab lives under `Prefabs/Resources` because code loads it with `Resources.Load`. Any asset loaded that way must remain under a `Resources` directory. Vendor prefabs remain inside `ThirdParty` so imported packages can retain their hierarchy and licenses. Assets generated by Unity's Test Runner are temporary and are not part of the source hierarchy.

The one-time studio migration is recorded in `AssetHierarchyManifest.json`. It lists each individually moved asset and imported folder with its original GUID. Do not run `Tools/reorganize_assets.py --apply` again. Its `--check` command covers the whole historical studio layout and can report independent studio content violations.

The current vendor categories and package moves are documented in [ThirdPartyLayout.md](ThirdPartyLayout.md). Use `python3 Tools/thirdparty_audit.py` for a focused, read-only check of vendor `.meta` pairing, GUID inventory, package placement, retired folder references and active source paths.

`Last Signal > Validation > Audit asset hierarchy and Inspector references` loads studio prefabs, production and validation scenes, and data assets. It checks for missing scripts, unresolved serialized GUIDs in studio content, and enabled build scenes, then writes `AssetHierarchyAudit.txt`. The historical recovery scene and Unity template rendering settings are excluded from the GUID scan. The check deliberately does not treat every empty Inspector object field as a missing reference; many are intentionally unset. A full Edit/Play test run and standalone build are still required after changing asset paths or dependencies.
