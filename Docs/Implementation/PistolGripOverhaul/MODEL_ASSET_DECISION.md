# Retain the existing pistol and armature

The MRPoly Tactical Pistol is approximately 0.2405 m long at native scale. Its main mesh has 1,562 vertices and 1,041 triangles, 1,562 normals and 1,562 UV entries. It provides a recognizable frame/slide, barrel, trigger/guard, sights and a separate magazine. Handle cross-sections span approximately x=0.039–0.061 m; measurements at several heights informed contact authoring.

Source: `Assets/ThirdParty/Weapons/MRPoly/Low Poly Weapons Set/Models/Tactical Pistol.fbx`. Production references remain the existing MRPoly prefab and project-owned S021 wrappers. Existing URP/Lit project materials are retained: black/gray metal metallic 0.53, smoothness 0.52; polymer metallic 0, smoothness 0.338. No source mesh, license/provenance file or vendor material was modified.

The current anatomical defect does not require replacing this mesh or the functional 15-joint FPS hand. Blender is available at `/Applications/Blender.app/Contents/MacOS/Blender`, but no Blender model/export was created. Inventing another blocky pistol would not improve this grip problem.

The asset remains deliberately low-poly and uses simple color materials. It is not equivalent to VEIN's close-up surface detail. A higher-detail art replacement would require an original detailed mesh/material pass and separate art review; this revision does not claim that visual fidelity. UV/normal array presence is not a full texture or topology quality certification.
