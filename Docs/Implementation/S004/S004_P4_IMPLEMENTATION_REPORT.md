## 26. CLOSE RANGE MUZZLE FIX
The production rifle exhibited a failure at very close ranges where the physical muzzle origin was placed inside the target's `EnemyHitRegion` colliders, causing the `Physics.Raycast` obstruction check to start inside the collider and miss. The resolver was updated to perform a `Physics.Linecast` from `cameraOrigin` to `muzzlePosition` before the forward raycast. If the linecast hits a collider, it signifies the weapon barrel has physically clipped into or through an object. In such cases, the shot is immediately resolved against the clipped collider (`clipHit.collider`), applying damage correctly to a close-range zombie while still correctly obstructing if clipping through a wall. This provides physically coherent close-range hit registration.
