# Three-model manual visual acceptance

NOT_RUN — USER OWNED. Record separate evidence for DXT, Glock17 and Custom9mm in the real S013Cabin production scene. Repeat the route in daylight, indoors, at night and under the flashlight; do not alter global lighting to conceal a material issue.

For EACH model record:
- [ ] Low-ready idle, raised-ready after a shot and smooth return: environment remains readable.
- [ ] ADS across supported FOV/aspect ratios: rear/front sights align; palm stays on the actual handle.
- [ ] Side/front hand inspection: wrist natural, forearm continuous, thumb opposes the grip, middle/ring/little wrap without gaps or penetration, index rests/pulls plausibly.
- [ ] Accepted shots: one recoil/audio/noise event; muzzle flash at barrel, casing at port, slide and trigger move only on that model, bounded recovery.
- [ ] Tactical and empty reload: real magazine follows its well, left hand actually meets it, right hand holds weapon; insertion timing matches commit and empty handling.
- [ ] Cancel before and after reload commit; switch rapidly across all models; repeat while aiming and opening inventory. No growing reserve, new magazine, lingering magazine/slide or stale FOV.
- [ ] Walk/sprint/crouch/slide: no arm separation, clipping, weapon floating, snapping or excessive wrist bend.
- [ ] Equip/unequip: player-driven cycling lowers the outgoing pistol before swapping; save restoration and forced direct selection are immediate.
- [ ] Diesel idle/aim/fire/reload in inspection camera: right-hand ownership, natural shoulder/elbow, left hand independent except reload, no duplicate world weapon.
- [ ] Death, disable/enable, vehicle entry/exit, camera visibility changes and session teardown release presentation cleanly.
- [ ] Save each appearance while pistol, rifle and melee are selected; reload restores appearance, loaded rounds, reserve and condition.
- [ ] URP metal/plastic/roughness and normal-map direction under moving light; no black/pink material or excessive gloss.
- [ ] Rifle still has its original two-hand/stock behavior, ammo, ADS, reload, audio and world visibility.

Profile GPU/CPU, draw calls, texture memory and GC only in user-run acceptance. No performance PASS exists. Record model, state, scene/lighting, FOV, screenshot/video path, observed defect and VERIFIED_PASS/VERIFIED_FAIL only after actual review.
