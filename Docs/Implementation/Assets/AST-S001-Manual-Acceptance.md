# AST-S001 — Owner kontrolü (macOS / Windows)

Bu sprintte **taşıma olmadı**. Önce salt okunur kanıtı alın; üçüncü Move menüsünü çalıştırmayın. UI paketi Resources bağımlılığı nedeniyle adaylıktan çıktı. Forest yeniden üretim araçlarını çalıştırmayın. Üç source path düzeltildi; bu değişikliği doğrulamak için üretim yapmak gerekmiyor.

1. Unity **6000.5.0f1** içinde mevcut projenizi açın; açık sahnelerdeki kendi değişikliklerinizi istediğiniz şekilde kaydedin. Import/compile tamamlanana kadar bekleyin. Console'daki mevcut hata/uyarıları başlangıç kanıtı olarak kaydedin. HDRP 17.5.0 ve amaçlanan High quality profilini doğrulayın; ayar değiştirmeyin.
2. Önce `Tools > Last Signal > AST-S001 > 4 Dry Run Manifest (no writes)` seçin. Beklenen: 72 manifest satırı; BLOCKED gerekçeleri, Kenney için InputGlyphCatalog tüketicisi, kaynak GUID/meta ve yedek NOT_RUN ayrımı. Penceredeki export düğmesiyle raporu kaydedip iletin. İsteğe bağlı olarak Project penceresinde bir paket seçip `5 Validate Selected Package Backup (no writes)` kullanın; bu yalnız o paketin kaynak/yedek baytlarını okur. Onay/risk engelleri yedek eşleşse de kalkmamalı. Ardından `1 Dry Run Candidate UI (no writes)` seçin. Beklenen: `New dependency; batch requires review: Assets/LastSignal/Resources/InputGlyphCatalog.asset` nedeniyle işlem durur. Dosya/klasör taşınmamalı. Başka hata varsa aynen iletin; guard'ı atlamayın.
3. `Tools > Last Signal > AST-S001 > 2 Export Read-Only Dependencies` seçin. Console'un gösterdiği `Docs/Implementation/Assets/Evidence/editor-audit-<id>.json` dosyasını iletin. Bu rapor test/build çalıştırmaz ve sahneleri açıp kaydetmez; AssetDatabase dependency, Resources/preloaded ve forest prefab bilgisi okur. Compile hatası olursa Console stack trace ile durun.
4. Normal Editor akışında `Assets/LastSignal/Scenes/Production/FirstTownCore.unity` açın. Eksik script/prefab/material ve pembe obje olmadığını, player spawn, silah/animasyon/ses ve mevcut ağaç kesme/damage/falling/resource spawn davranışını kısa manuel Play oturumunda kontrol edin. Yalnız önceden çalışan save/load senaryosunu kullanın; yeni özellik beklenmez.
5. `Assets/LastSignal/Scenes/Validation/ForestPrototype120.unity` açın. European spruce/birch, fir hero ve fern görünümü, LOD geçişleri, trunk collider ve var olan graphics/tree-shadow seçeneklerini kontrol edin. Aynı kalite seviyesi ve kamera koşullarında belirgin yeni davranış farkı beklenmez. Yeni benchmark çalıştırmanız bu aşamada gerekli değil.
6. UI input glyph ikonları, gerekli weather/VFX/character/audio/vehicle öğelerinde önceden gözlenen davranışla karşılaştırın. Sorun bulursanız scene/prefab adı, Console logu, ekran görüntüsü ve üretme adımlarını iletin.

**Geri gönderilecek kanıt:** editor-audit JSON, ilk/son Console hata listesi, macOS/Windows + GPU/quality bilgisi, kontrol edilen sahneler ve PASS/FAIL notları. UI dry-run'ın beklenen blokajı bir test başarısızlığı değil güvenlik kapısıdır. Bu kanıt incelenmeden ACCEPTED veya ikinci batch yapılmaz.

macOS ve Windows menü yolu aynıdır. Audit tekrar taraması için proje kökünde macOS `python3 Tools/AssetAudit/audit.py`; Windows Python kuruluysa `py -3 Tools/AssetAudit/audit.py`. Bu komutlar Unity test/build başlatmaz. Yeni veri dizinini eski kanıtla karıştırmayın.

Sonraki sprint önerisi: **AST-S002 — source path onarımı, güncel paket checkpoint tamamlama, lisans kanıtı ve tek paket pilotu**. Fir/fern/ground için yapılan üç sabit düzeltmesi owner tarafından doğrulansın; rollback manifest semantiği ayrı diff içinde ele alınsın; mevcut üretim ormanı taşınmasın. **PERF-S001 devamı** gölge/LOD optimizasyonunu ayrı ölçümle yürütmeli. Silme/dedup için ancak sonraki açık owner onaylı cleanup aşaması açılmalı.

Path düzeltmesi kontrolü: `Assets/LastSignal/Scripts/Editor/FirstTownForest/ForestPrototypeAssets.cs` Fern/Fir/Ground sabitlerini ve Project penceresinde karşılık gelen `Assets/ThirdParty/fern_02_4k.blend`, `fir_tree_01_4k.blend (1)`, `forrest_ground_03_4k.blend/textures` kaynaklarını karşılaştırın. Var olan generated prefabları/sahneyi kaydetmek ya da regenerate komutu çalıştırmak gerekmez.
