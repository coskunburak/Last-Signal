# Combat impact audio provenance

The `impact*.ogg` files in this directory are copies of the supplied Kenney Impact Sounds assets under `Assets/ThirdParty/Audio/kenney_impact-sounds/Audio/`. Kenney Impact Sounds is CC0. These project-owned copies retain the audio content and set `forceToMono: 1` in their Unity import metadata so world-space impact cues use mono source audio. The vendor package and its metadata remain unchanged.

The `FleshImpact_*.wav` files are project-owned derivatives of the supplied CC0 visceral bullet impact recording, as documented in the combat feedback implementation report.
